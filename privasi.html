Kebijakan Privasi

Backup Kantor Otomatis adalah alat pribadi untuk mencadangkan file dari komputer kantor ke akun Google Drive yang dipilih pemilik akun.

Akses Google Drive

Aplikasi meminta izin untuk membaca dan mengelola file di Google Drive. Izin ini dapat mencakup seluruh Drive, meskipun proses backup normal hanya menulis cadangan ke folder BACKUP-KANTOR pada akun yang dihubungkan.

Penggunaan dan penyimpanan data

File sumber dibaca dari komputer kantor dan dikirim langsung ke Google Drive melalui rclone. Token akses Google disimpan secara lokal pada komputer backup agar jadwal otomatis dapat berjalan. Log lokal mencatat waktu, status, kesalahan, dan dapat memuat nama file.

Alat ini tidak mengirim file cadangan ke server milik pengembang dan tidak menjual data pengguna. File asli tidak dihapus oleh proses backup. File cadangan lama juga tidak dihapus secara otomatis; pemilik akun mengelola penghapusannya di Google Drive.

Kontrol pemilik akun

Pemilik akun dapat mencabut izin aplikasi melalui pengaturan keamanan Akun Google. Administrator komputer dapat menghentikan jadwal backup dan menghapus token serta log lokal saat aplikasi tidak lagi digunakan.
