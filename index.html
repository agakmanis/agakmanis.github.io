Backup Kantor Otomatis

Backup Kantor Otomatis adalah alat pribadi untuk mencadangkan file dari komputer kantor ke Google Drive milik pemilik akun.

Setelah pemilik akun memberi izin satu kali, alat ini menjalankan backup setiap enam jam. File asli di komputer tidak dihapus. File lama di Google Drive tetap disimpan, termasuk versi sebelumnya dari file yang diperbarui.

Aplikasi menggunakan akses Google Drive untuk mengunggah dan mengelola file cadangan. Baca Kebijakan Privasi untuk mengetahui cara akses dan penyimpanan data.
