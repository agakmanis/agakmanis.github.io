Syarat dan Ketentuan

Dengan menggunakan Backup Kantor Otomatis, Anda menyetujui syarat dan ketentuan berikut.

Penggunaan aplikasi

Aplikasi ini digunakan untuk mencadangkan file dari komputer kantor ke Google Drive milik pengguna. Pengguna bertanggung jawab memastikan bahwa ia memiliki hak untuk mengakses dan mencadangkan file tersebut.

Akun dan izin Google

Pengguna bertanggung jawab atas akun Google yang dihubungkan, izin akses Google Drive, dan keamanan komputer tempat aplikasi dijalankan. Pengguna dapat mencabut izin aplikasi melalui pengaturan keamanan Akun Google.

Jadwal dan keandalan backup

Aplikasi mencoba menjalankan backup setiap enam jam. Backup dapat gagal apabila komputer mati, folder sumber tidak tersedia, akun Google tidak dapat diakses, atau koneksi internet bermasalah. Aplikasi akan mencoba ulang upload sesuai konfigurasi yang tersedia.

Data dan penghapusan

File lokal tidak dihapus oleh proses backup. File backup lama di Google Drive juga tidak dihapus otomatis. Pengguna bertanggung jawab mengelola kapasitas penyimpanan dan menghapus data yang tidak lagi diperlukan.

Batas tanggung jawab

Aplikasi disediakan untuk penggunaan pribadi sesuai konfigurasi pengguna. Tidak ada jaminan bahwa setiap file akan selalu berhasil dicadangkan. Pengguna tetap perlu memeriksa log dan hasil backup secara berkala.

Perubahan ketentuan

Ketentuan ini dapat diperbarui apabila fungsi atau cara penggunaan aplikasi berubah.
